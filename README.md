# 🚀 Online Job Portal System

A full-stack **Online Job Portal System** developed using **Python and Django**.

This project provides separate modules for **Admin, Recruiter, and Job Seeker/User**.

## ✨ Features

### 👨‍💼 Admin
- Admin Login
- Manage Recruiters
- View Users
- Accept/Reject Recruiter Requests
- Manage Recruiter Status

### 🏢 Recruiter
- Recruiter Registration
- Recruiter Login
- Recruiter Profile
- Add New Jobs
- Edit Job Details
- Manage Job Vacancies
- View Applications

### 👨‍🎓 Job Seeker
- User Registration
- User Login
- User Profile
- View Latest Jobs
- View Job Details
- Apply for Jobs
- Upload Resume
- Check Applied Jobs
- Job Application Deadline
- Expired Job Detection

## 🛠️ Technologies Used

- Python
- Django
- SQLite
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
